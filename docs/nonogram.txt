OverlappingTrick:
with each trimmed clue, we calculate 
startRemain = [trimmed line length] - sum [clue and space except first number]
base on startRemain, we have a box [start-begin, start-begin + startRemain] 	
the overlap between ranges [start-begin, start-begin + first number] and [start-begin + startRemain - first number, start-begin + startRemain]
should be Filled.
and do the same with end:
endRemain = [line length, we trim crossed cells at begin/end] - sum [clue and space except last number]

Simple crosses

Overlapping

Spreading
when you have one or more boxes near the border or a cross.

Forcing
When you already have some crosses in the line, you can try to fit (force) the clues in the line.

If a clue equals the line length (e.g., 10 in a 10-cell row), fill the entire line.
If the sum of clues plus minimum required spaces exceeds the line length, apply immediate overlaps (see next step).

For a line of length L with a run of length N, if you slide the run from leftmost to rightmost legal positions, 
any cell that stays filled in all positions is guaranteed.

After each row update, scan the affected columns for new overlaps, then return to rows. Repeat.

```
firstFilled = [cell that must be part of the first clue = first filled cell and [distance from it to edge less than or equal first clue

ac = clues[0] - x
if ac > 0:
  → mark cells [firstFilled + 1 .. firstFilled + ac - 1] as 'filled'

Symmetrically from right:
lastFilled = last 'filled' index in trimmedLine
x = trimmedEnd - lastFilled
ac = clues[last] - x
if ac > 0:
  → mark cells [lastFilled - ac + 1 .. lastFilled - 1] as 'filled'
```
