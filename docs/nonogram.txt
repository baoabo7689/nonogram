Simple crosses trick: 
ví dụ clue có 2 num, trên line có 2 cell filled 
mà khoảng cách giữa 2 cell > giá trị 2 num 
=> 2 cell nằm ở 2 giá trị khác nhau 
=> cell1 = num1, cell2 = num2
=> cell1 chỉ có thể phủ từ [x - num1, x + num1] nên các cell khác crossed 
tương tự cell2 chỉ có thể phủ từ [x - num2, x + num2] nên các cell khác crossed  


OverlappingTrick:
with each trimmed clue, we calculate 
startRemain = [trimmed line length] - sum [clue and space except first number]
base on startRemain, we have a box [start-begin, start-begin + startRemain] 	
the overlap between ranges [start-begin, start-begin + first number] and [start-begin + startRemain - first number, start-begin + startRemain]
should be Filled.
and do the same with end:
endRemain = [line length, we trim crossed cells at begin/end] - sum [clue and space except last number]

[OverlappingTrick can be work with Simple crosses trick, to mark some center cells Filled]


Spreading trick:
get first filled cell in trimmed line, 
calculate distince it to egde of trimmed line = x 
if ac = [number1 - x] > 0 then [ac cells] follow that first cell must be Filled 
same as with the last filled cell in trimmed line


Forcing trick: 
get first Crossed cell in trimmed line, 
calculate distince it to egde of trimmed line = x 
if x < number1 then all cell front of that cell must be Crossed 
we can continue recursive when can be 
do the same for the last Crossed cell in trimmed line

If a clue equals the line length (e.g., 10 in a 10-cell row), fill the entire line.
If the sum of clues plus minimum required spaces exceeds the line length, apply immediate overlaps (see next step).

For a line of length L with a run of length N, if you slide the run from leftmost to rightmost legal positions,
